# Spartan Event Hub

## Project Description

Spartan Event Hub is a website that helps students find events happening on campus. I made a home page that shows different upcoming events and another page that gives more information about one featured event.

The website is for students who want to find activities and get more involved on campus.

## Layout Decisions

For this project, I used Flexbox and CSS Grid.

I used Flexbox for the navigation, hero section, and related events. I used it because it helped me put items next to each other and control the space between them.

I used CSS Grid for the event cards on the home page. The first event is bigger than the other events because it is the featured event.

I also used Grid on the event page. On a desktop screen, the main event information is on the left and the event details are on the right.

## Responsive Design

I used two media queries in my CSS.

The first breakpoint is at 800px. At this size, some parts of the page start stacking instead of staying next to each other. The sidebar on the event page also moves under the main content.

The second breakpoint is at 550px. This is for smaller phone screens. The navigation becomes vertical and the event cards show in one column.

I tested the website by making my browser window smaller and bigger to see how the pages changed on different screen sizes.

## Semantic HTML

I used different semantic HTML elements in my pages.

I used `header` for the top part of the website and `nav` for the navigation links. I used `main` for the main content and `section` to separate different parts of the page.

I used `article` for the event cards and `aside` for the extra event information. I also used `figure` and `figcaption` for images and `footer` for the bottom part of the website.
